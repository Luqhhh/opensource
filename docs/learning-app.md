# 面向学习者的项目入口

导入想学习的项目、描述目标，再按任务开始行动。学习空间使用路线目录、当前任务和并排原文阅读布局，采用用户选定的 B「纸感青绿」方向：象牙白任务纸面、浅青绿目录与深绿主操作，放大正文和辅助文字，并将帮助入口分离为轻量工具条；移动端按目录、任务、原文排列。[learning-ui-baseline.json](learning-ui-baseline.json) 保留此前 v2 设计的历史接受记录，不代表当前前端快照。

任务页按“任务标题 → 现在做 → 完成标志 → 完成并继续”排列。项目导航移到顶部，目录和进度降低视觉权重；长操作按原句分层显示，补充说明可展开，完整内容仍保留。前提、问答、笔记、练习、运行和路线调整按需打开，每次只展开一个工具面板，切换工具不会重建或清空输入表单。原文默认显示当前引用中的至多 22 行，可展开全文；搜索或函数定位超出节选时自动切换全文，阅读历史仍可返回。此调整只改变展示方式，不重新生成路线或改变学习记录。

当前任务同时显示操作位置、完成标准与下一步标题；完成记录成功保存后才进入下一步，失败提示留在操作旁。已完成步骤提供继续下一步与撤销完成两个入口。项目阅读提示和背景介绍按需展开。

桌面布局可收起目录，通过拖动任务与原文之间的分隔条调整宽度。分隔条支持左右方向键调整、Home/End 到边界、Enter 或双击恢复默认比例。目录开关与阅读比例保存在当前浏览器；调整布局不会重建表单。窄屏改为上下排列，并提供当前任务与原文跳转入口。专注任务模式可随时退出。

问答、笔记、练习、运行及路线调整均直接展示，窄屏自动换行。左上角例证标识和品牌文字、当前仓库名称，以及学习路线、项目文件、学习记录、项目评估四个模块入口均采用更醒目的字号和字重，当前模块以青绿背景和底边标记。按钮采用统一的主次、焦点、禁用和处理中状态；恢复学习提示、笔记保存状态、阅读位置状态与问答错误均在对应区域展示。减少动态效果及系统强制颜色模式保留键盘焦点与可辨识状态。

## 启动与使用

```sh
python3 -m exampleproof learn --port 8765
# 不使用模型也能阅读、记录、调整路线及获得本地排错线索：
python3 -m exampleproof learn --provider none
# 已安装并启动的本地模型：
python3 -m exampleproof learn --provider ollama --model YOUR_MODEL
```

访问 `http://127.0.0.1:8765/`。上传源码 ZIP 或填写公开 GitHub 地址，输入学习目标和基础水平。配置模型后，导入页默认勾选「自动用 AI 细化学习路线」；点击「创建 AI 学习路线」后，后台先整理项目，再自动使用学习目标与经脱敏的项目片段生成 AI 路线，不需要进入项目后再次点击。处理中可离开页面，重新打开会显示当前进度或已完成的路线，不会重复调用模型。

取消勾选时仅生成本机基础路线，之后仍可查看发送内容并手动启用 AI。未配置模型时直接使用基础路线；AI 失败时保留基础路线、显示错误并提供手动重试，不会自动反复请求。既有项目不会因为打开、刷新或重启服务而自动发送内容。问答与重新规划仍采用各自的预览确认流程。

自动细化记录导入时的 `auto_ai` 选择和 `ai_trigger: import_choice`。云端请求仍受固定快照、脱敏载荷及模型绑定校验，但其授权来自导入时选择 AI，不代表用户逐段审阅过发送清单。直接使用 HTTP 接口时，GitHub 导入须在 JSON 中传 `auto_ai: true`，ZIP 导入须在查询参数中传 `auto_ai=true`；省略或传 false 保留先预览再手动生成的兼容行为。

## 任务、问答与阅读

每步显示要做什么、原文位置、开始前的环境与概念、应观察的结果。基础路线会将可解析的短 Python 文档示例拆成连续操作，保留原代码和精确引用；提示沿用前一步的变量与会话。AI 路线提示要求具体操作、运行位置和可观察结果，可补充逐步前提；未知工作目录和输出必须说明。解析不保证语义正确，仍需对照原文。

任务与原文旁提供“解释这段”“给一点提示”“我遇到了报错”。问题关联学习目标、当前步骤、选中原文、最多四条近期讨论及有限的相关片段。排错还保存实际环境、命令和错误内容。练习支持预测输出、改变一个条件、解释两处代码的关系。反馈与后续检查操作必须引用本次提供的原文，非法引用或格式拒绝采用；失败保留调用记录，不伪装成成功。

AI 问答先展示实际发送预览，确认绑定到该问题、路线与片段；云端继续使用原有精确请求绑定及脱敏。预览不发送请求，不会自动把全部笔记传给模型。无模型或选择本地线索时，提供规则生成的阅读与排错检查项，明确标注来源，不能替代语义回答或理解评判。

当前步骤的问答按时间连续展示，默认显示最近 12 条，可展开更早记录。回答中的引用直接打开原文阅读区；「继续追问」明确关联选定回答，并将其纳入最多四条对话上下文，较早回答也不会被近期记录挤掉。跨步骤或练习反馈不能作为追问对象。「预览并提问」先展示问题、关联回答及所选原文，确认后才发送；取消预览保留输入。准备、生成和断网时阻止重复发送，断网可重新检查原请求状态，生成失败可保留问题重新预览。后台请求在重新进入项目时可恢复其已脱敏的问题草稿；问答记录成功保存后只清理对应的已发送草稿，保留后来输入的内容。

文档支持基础 Markdown/部分 RST 正文、章节目录、代码块、列表与链接；原始 HTML 作为文字显示，不执行。原文阅读使用本地词法着色，区分关键字、函数名、字符串、数字、注释等，按文件扩展名或 Markdown 代码围栏标注识别语言；多行字符串和注释连续着色。常见 Python、JavaScript/TypeScript、JSON、YAML、TOML、Shell、HTML/CSS 及 C/C++、Java、Go、Rust 提供基础着色，未知语言保留为纯文本；这是词法提示，不是完整语法解析或语义检查，嵌入语言等复杂语法可能只得到近似着色。行号栏横向滚动时固定，引用与搜索定位有不同底色，缩进参考线按四列显示。自动换行保留原始行号并记住浏览器偏好；复制节选或全文直接读取原文，不带行号与着色标签，剪贴板不可用时提供只读文本手动复制。代码提供轻量词法高亮、文件内搜索、Python AST 函数/类定位，以及其他常见语言的有限符号定位。依据示例中的调用名称显示同名定义入口；这是静态线索，不能保证调用关系。内部文档链接跳到已导入文件，阅读历史保存文件、引用、滚动位置与模式，可前进、返回和刷新恢复。复杂 Markdown/RST 指令、表格、跨语言语义导航尚不支持，可切回原文查看。

## 练习、运行和完成状态

三种记录分开保存：用户自行标记的步骤完成、练习回答与 AI/本地反馈、实际隔离运行结果。任何一种都不自动推导“已经掌握”。

可选运行检查接受用户明确提交的完整 Python 示例（最多 6,000 字符），调用已有 `SandboxRunner`，项目副本只读、无网络、最多 5 秒，不安装第三方依赖，不执行模型建议的命令。Bubblewrap 不可用时记录 `blocked`，没有宿主执行回退。运行的标准输出、错误、耗时、代码、来源步骤与状态独立保存；运行失败可带着该结果进入排错。没有提供独立行为断言，因此“执行结束”不等于预期行为正确；用户代码中的断言也不是独立证据。其他语言、外部服务和额外依赖暂不在这个执行入口支持范围内。

导入、阅读和 AI 分析本身不执行项目代码。只有用户点击运行检查才执行所提交的示例及其导入代码，且始终在隔离执行器内。

## 保存、继续与路线调整

步骤、阅读位置、笔记、原文关联、未解决问题、练习和调整均保存在本机项目目录的 `study.json`。笔记采用版本检查与原子写入；其他页面更新同一笔记时阻止静默覆盖，并提供显式合并。浏览器 localStorage 用于未同步笔记草稿备份、旧版笔记迁移和布局偏好；学习记录在本机服务保存完成后不依赖该浏览器。旧笔记会在打开对应步骤时迁移。浏览器与本机磁盘均不可写时，页面提示复制草稿。

重新进入项目显示上次停留的位置。“学习记录”统一显示笔记、问题、练习、运行和路线历史，可导出文字记录；指南导出与学习记录导出各自保留。准备发送但未确认的问答不算已完成的讨论；服务重启打断的模型请求显示失败，已有学习记录不受影响。

“已经会了”“这步太难”“当前不需要”先展示建议，用户可选择跳过、拆分成三个小任务或补看前提。调整立即可见、有历史记录并可撤销。跳过不计入完成；拆分勾选也不会自动完成整步。当前不做隐式自动推荐。

AI 路线可重新规划。每次保留旧路线、原有完成标记、笔记、讨论、练习、运行和调整，新路线重新记录进度；相同标题也按版本隔离。此前版本的云请求预览继续使用其原提示完成绑定，新预览使用新提示，不通过改写旧记录绕过确认。

## 数据、边界与验证

- 默认数据目录为 `~/.local/share/exampleproof-learning`；`--data PATH` 可更换。最多 100 个项目，每项目最多 80 个路线版本、1,000 条笔记、500 条讨论、300 条运行记录、2,000 条调整事件；阅读历史保留最近 30 处。达到限额时提示导出。暂无前端删除功能，保留策略由本机用户管理。
- 使用现有项目发现、静态索引、缺失主张补查、脱敏和模型客户端。路线片段最多 20,000 字符；问答最多 8 处片段、片段文本共 18,000 字符。原始调用、用量和失败记录留在本机项目目录。原文引用有效不代表结论一定正确。
- ZIP 最大 20 MB，展开最大 64 MB、最多 20,000 个条目；导入最多 1,000 个合格 UTF-8 文件，共 8 MB、单文件 256 KB。拒绝路径穿越，跳过符号链接、敏感文件名、依赖和二进制。界面说明分析覆盖范围。
- GitHub 使用固定提交快照，只支持公开仓库；私有源码可用本机 ZIP 导入。模型发送仍需选择与预览，不接收私有仓库令牌。
- 服务监听 `127.0.0.1`，校验 Host、Origin 和写请求令牌。单人本机使用，不具备账号隔离、公开服务鉴权或多租户队列，不能直接公开部署。
- Python 运行依赖仍为标准库，前端为原生 HTML/CSS/JavaScript；可选执行复用已有 Bubblewrap，不增加第三方库、模型、字体或图像。

新增单元与浏览器检查属于助手编写的合成工程验证，分别覆盖真实 HTTP/保存/隔离执行与合成模型生命周期，不是独立读者研究或真实模型质量评测。既有断言、冻结评测和历史结果保持不变；本轮不据此声称学习效率提升、维护者采纳或参赛结果。

可运行 `python3 scripts/build_learning_ui_fixture.py --output /tmp/exampleproof-ui`，再用浏览器打开生成的 `index.html` 或 `viewport-390.html` 等固定视口页面，复查布局、追问、草稿保留和失败重试；页面底部输出检查结果。加 `?preview=1` 仅预览。夹具使用独立合成项目及内存响应，不访问真实模型或用户学习数据，不执行项目代码，不增加第三方依赖。

原文高亮的合成词法检查可运行 `node tests/code_highlight.test.cjs`（Node 仅用于开发验证，不是应用运行依赖）；上述浏览器夹具还覆盖多行着色、危险 HTML 转义、行号固定、长行换行、原文复制与剪贴板拒绝时的降级、文档语言标注及阅读历史。`?preview=reader` 可预览代码阅读区。
