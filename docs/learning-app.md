# 面向学习者的项目入口

产品主线是导入想学习的项目、描述目标，再按指南开始行动。用户不用填写任务合同或评测表单。之前的离线证据工作台是内部研究资料，不是这个产品入口。

## 启动与使用

```sh
python3 -m exampleproof learn --port 8765
# 不使用模型也能整理原文和静态观察：
python3 -m exampleproof learn --provider none
# 已自行安装并启动的本地模型：
python3 -m exampleproof learn --provider ollama --model YOUR_MODEL
```

浏览器访问 `http://127.0.0.1:8765/`。上传源码 ZIP 或填写公开 GitHub 地址，输入想完成的事并选择基础水平。本地分析会给出环境声明、文档中的命令、关键文件、静态观察和基础路线。模型已配置时，用户可查看实际发送片段，再选择 AI 细化路线。

每一步有行动、完成标志和可点击的原文引用。支持按步骤标记进度、搜索项目文件、查看高亮原文、导出文字指南，并在“我的学习项目”继续学习。完成标记为用户自行记录，不能计为独立任务验证结果。

## 实现范围

- 使用现有项目发现、AST/关键词检索、静态检查、缺失主张补查、脱敏、精确云请求绑定与模型客户端。增加面向学习者的提示和严格结构校验；每项 AI 步骤、前提与发现必须引用本次提供的片段 ID。
- 一次 AI 增强调用，证据 JSON 最多 20,000 字符；原始调用、实际 token 和失败结果保存在本机项目目录。非法引用拒绝采用；服务或解析失败保留基础指南并明确显示错误，不伪装为 AI 成功。
- ZIP 支持顶层源码或单一包装目录，最大 20 MB、展开最大 64 MB、最多 20,000 个条目。只保留最多 1,000 个合格 UTF-8 文本文件、共 8 MB、单文件 256 KB，拒绝路径穿越，跳过符号链接、敏感文件名、依赖和二进制。不是所有文件都参与分析，页面会说明读取范围。
- GitHub 使用现有固定提交快照接口；只支持公开仓库，不接收私有仓库令牌。ZIP 可在本机分析私有项目，云端增强仍由用户单独选择。
- 不安装项目依赖、不导入或运行上传代码、不执行模型给出的命令。基础路线的命令来自原文；AI 内容仍需结合原文核对。
- 默认数据目录为 `~/.local/share/exampleproof-learning`；用 `--data PATH` 可更换。记录与进度跨服务重启保存；被重启打断的任务显示中断状态。最多两个并发任务、100 个保存项目；暂无前端删除功能。
- 服务仅监听 `127.0.0.1`，校验 Host、Origin 和写请求令牌。无账号、多租户、配额计费、公开服务鉴权或生产托管；不能直接暴露到公网供多人共享。运行时依赖仍为 Python 标准库，前端无框架或外部资源。

## 质量边界与下一步

已验证导入、目标路线、引用查看、进度持久化与导出等工程流程；这些检查不能证明学习效率提升。已有四任务基线继续独立保存，新学习提示不改写旧评测结果。

后续可优先做带项目依据的问答与报错解释、按操作系统提供环境准备步骤、源码概念关系导航，以及独立任务验证。公开服务需要另外完成账户隔离、上传保留/删除策略、队列、鉴权和使用配额。
