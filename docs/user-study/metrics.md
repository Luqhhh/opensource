# 真实用户体验记录指标

指标用于描述真实使用过程和安排改进，不用于模型性能排名。先保留逐人逐任务记录，再作描述性汇总；没有记录的字段为空或NA，不填0。

| 指标 | 记录方法 | 汇报方式 |
| --- | --- | --- |
| 任务结果 | 独立完成、协助完成、未完成、环境受阻、退出 | 列实际人数或任务数与分母，受阻退出单列 |
| 任务用时 | 从读完任务到完成或停止的实际秒数；暂停另记 | 中位数与范围，说明任务与参与者；不宣称因果提升 |
| 求助 | 向主持人求助次数、最高帮助级别H0–H3 | 说明何处需要何种帮助；AI问答次数另列 |
| 操作卡点 | 时间、位置、行为、原话、是否恢复 | 组织具体故事，列出现次数与改进动作 |
| 体验问卷 | 五题逐项1–5或NA，原题保留 | 每题分布或中位数，不拼成综合能力分 |
| 恢复学习 | 找到任务、笔记与阅读位置，是否需要帮助 | 描述实际过程 |
| 继续使用意愿 | 第五题及原因，允许“不愿意” | 结合具体场景和保留意见 |
| 外部复现 | 安装、启动、导入、笔记恢复、导出及环境 | 写明实际复现者编号及问题 |

elapsed_seconds为实际经过时间，paused_seconds为暂停；若计算活动时间，显式相减并保留原值。未完成与受阻用时单列，不当作完成耗时。问卷不是SUS，不套用SUS解释或行业基准。

## 汇总结构

1. 实际参与者范围、熟悉度、作品版本、项目、模型模式。
2. 两到三个体现帮助或困难的真实任务过程，附经同意的匿名引语。
3. 完成状态、实际耗时与帮助的描述性摘要，明确未观察项。
4. 问题与改动：反馈编号、界面位置、改动、复查状态。
5. 实际限制：便利招募、小样本、主持人帮助、网络故障等。

不回填推测数据，不把演示操作者或自动浏览器当作受访者。重复任务不增加独立参与人数。仅主张本次观察支持的体验结论。
