# 例证真实读者试用方案

本轮通过真实操作观察和访谈，了解学习者能否用例证找到入口、理解原文、完成小任务并在中断后继续，以及哪些地方造成困惑。

计划邀请6–8位具有基础 Python 阅读能力、未参与例证开发的同学；每人约30分钟，选择一个自己不熟悉的项目。招募人数是组织建议，不是已经完成的样本量。现有用户也可参加，但单独记录使用经历。

## 推荐项目

| 项目 | 推荐对象与任务 | 固定来源 |
| --- | --- | --- |
| TinyDB | 会读字典、条件表达式的学习者；保存学习条目、筛选未完成内容、关闭重开后确认数据 | [固定提交 edff96ae](https://github.com/msiemens/tinydb/tree/edff96aeb2616402e9489d46e90a592c05565621)，MIT |
| Schedule | 会读函数与回调的学习者；注册带标签的提醒任务，按需运行并仅取消指定任务 | [固定提交 82a43db1](https://github.com/dbader/schedule/tree/82a43db1b938d8fdf60103bd41f329e06c8d3651)，MIT |

两个项目均为纯 Python，便于阅读小范围源码。本次不要求学习者安装项目依赖；主持人在试用前确认例证的隔离运行环境。Schedule 任务使用有界的一次执行，不运行 README 中的无限循环，也不要求时区扩展。桌面试用包提供固定提交的原始 ZIP 和 SHA256；保留上游许可证，未修改上游文件。

项目是否对受访者陌生，以本人回答为准。

## 使用材料

1. 将 [受访者说明](participant-guide.md) 单独交给受访者；它包含同意事项、操作安排和无答案任务卡。
2. 主持人阅读 [主持人手册](facilitator-guide.md)，准备独立数据目录、模型与沙箱，避免临场安装。
3. 用 [观察记录表](observations.csv)、[体验问卷](questionnaire.csv) 和 [访谈表](interviews.csv) 记录真实过程。空白表不含模拟受访者。
4. 按 [指标与汇总口径](metrics.md) 整理结果，将可追溯的观察、原话和改进动作写入 [用户体验记录](results.md)。

## 每场安排

| 阶段 | 时间参考 | 内容 |
| --- | --- | --- |
| 确认与背景 | 3分钟 | 自愿参加、录屏选择、Python基础、是否用过项目 |
| 导入与定位 | 5分钟 | 输入自己的目标，创建路线，找到下一步与原文 |
| 完成两个任务 | 12–15分钟 | 自主操作；可提问、查原文、运行完整示例、求助 |
| 中断后恢复 | 3分钟 | 保存笔记、关闭页面、重新进入并找到刚才位置 |
| 问卷与访谈 | 5分钟 | 说出有用与困惑之处，回顾最具体的卡点 |

时间参考用于安排场次，不构成能力考试。单项卡住3分钟可询问是否需要帮助；用户随时可以停止。参与者编号P01、P02等不对应公开姓名，实际联系表另行保管。

## 主持人事先确认

- 使用同一个作品版本，记录提交号；中途修复后分开记录，不混成同一版本体验。
- 同一轮尽量使用同一种模型模式；服务失败或无模型时记明实际模式，不把基础路线试用说成 AI 试用。
- 每名参与者使用独立的 `--data` 目录。录屏只截应用区域，经本人选择后开启。
- 完整示例只通过既有隔离运行入口执行。运行不可用时继续阅读与问答，将执行子任务记为环境受阻。
- 只向模型发送公开项目片段与参与者同意发送的问题，不采集私人源码、账号、成绩或学号。

## 保存与公开

对外使用匿名任务过程、经同意的引语和汇总。联系方式、未脱敏录屏与私人对话不进入公开仓库。原始记录在本次材料确认后30天内删除，或由参与者另行同意保留；删除请求由主持人受理。

正式体验回收前，报告只能说明已提供流程与试用方案。实际参与人数、感受与完成表现从真实记录填写，不能用自动浏览器操作、开发者体验或空白表格补足。
