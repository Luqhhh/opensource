这是一场约30分钟的产品体验，想了解开源项目学习过程中哪些地方有帮助、哪些地方令人困惑。我们观察工具，不给你的编程能力打分。

你可以随时暂停、跳过任务或退出；不需要提供姓名、学号、学校或私人代码。主持人会使用P01这样的编号记录。录屏和匿名引用分别征求同意，不同意录屏也可以参加。

开始前请口头或勾选确认：

- [ ] 我愿意参加，并知道可以随时停止。
- [ ] 我同意记录匿名操作过程与问卷回答。

- [ ] 我同意在报告中引用经过脱敏的原话（可不选）。

## 你需要做什么

1. 告诉主持人：是否学过 Python、是否接触过这个项目、平时如何开始学习陌生项目。
2. 打开源途页面，上传分配给你的项目 ZIP，填写学习目标，创建学习路线。
3. 使用路线、原文、问答、笔记等功能尝试下面的任务。可以按自己的方式操作，也可以求助。
4. 遇到困惑时说出当时的想法，例如“我以为这里会显示运行结果”。不需要边操作边评分。
5. 保存一条笔记，关闭页面，重新进入项目，找到刚才的任务和笔记。
6. 回答体验问题。没做完也有价值，请直接说明卡在哪里。

如果使用“运行”，粘贴完整 Python 示例。每次运行都是新会话，不会记住上一次的变量和临时文件；不要在系统终端执行下载项目或AI建议的命令。运行环境不可用时请告诉主持人。

## 任务卡 A TinyDB

**场景：** 用一个轻量工具保存学习清单。请根据原文与工作台提示完成任务，不需要事先知道TinyDB。

**输入目标：** 用 TinyDB 保存两条学习记录，查询未完成的记录，并确认关闭数据库后重新打开仍可读到数据。

**任务一：保存与查询。** 保存两条记录：一条标题为“阅读入门”、已完成；另一条标题为“练习查询”、未完成。让程序只显示未完成的记录。找到一处帮助你理解查询写法的原文。

**任务二：再次读取。** 在一个完整示例内关闭数据库，再次打开同一个文件，确认记录仍然存在。用自己的话说明文件保存在哪里，以及为什么下一次点击“运行”不能直接沿用上一次的临时文件。

不知道如何操作时，可以在当前任务旁提问。结果可以是运行输出，也可以是一份写到中途的示例与具体问题；请保留真实过程。

## 任务卡 B Schedule

**场景：** 给小程序设置不同提醒，并且能只取消其中一种提醒。

**输入目标：** 用 Schedule 注册两个带不同标签的提醒任务，一次运行已注册任务，再只取消一个标签对应的任务。

**任务一：注册与执行。** 创建两个回调：一个输出“喝水”，一个输出“伸展”；分别使用 `water`、`stretch` 标签。找到不需要无限等待就能执行已注册任务的方法，运行一次并查看输出。

**任务二：按标签取消。** 只取消 `water` 标签对应的任务，确认另一个任务仍然保留，再运行一次。找到支持操作的原文，并说明注册任务与执行任务的区别。

本场不使用无限循环、后台服务或时区扩展。完整示例应在5秒内结束；超时表示本次运行超出限制。

再告诉主持人：最有帮助的一个地方、最困惑的一个地方、希望优先改变什么。请尽量举出刚才发生的具体例子。
